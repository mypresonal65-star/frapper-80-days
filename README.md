# 🚀 Frappe & ERPNext 80-Days Mastery Tracker App

Ek personal interactive web app jo aapko zero se lekar advanced Frappe Framework aur ERPNext developer banane ke liye daily track karti hai, aur har **2 ghante me alarm ghanti bajakar** study karne ke liye force karti hai!

---

## ✨ Features (Kya-kya shamil hai):

1. **80 Din ka Complete Daily Roadmap**:
   - Har ek din ke aage kya padhna hai, kya practice karni hai, aur free video/docs link diya gaya hai.
   - **Tick Button (✓)**: Roz ka kaam hote hi click karein, progress instantly update hogi aur persistent save rahegi (LocalStorage).

2. **⏰ Har 2 Ghante me Alarm & Forceful Reminder**:
   - Browser me timer chalta rahega.
   - Jab 2 ghante pure honge aur aaj ka task pending hoga, toh:
     - 🔊 **Zor se Ghanti/Alarm bajeegi** (continuous loop jab tak aap stop ya complete na karein).
     - 🚨 Screen par pulsing **Forceful Alert Popup** aayega jo batayega: *"Utho! Aaj ka Day X topic pending hai!"*
     - 🔔 Desktop par Windows notification aayegi jisme pending topic ka naam likha hoga.

3. **🎵 Customizable Ringtones (Change Ringtone)**:
   - 🚨 *Loud Emergency Alarm* (High-pitched siren)
   - 🏫 *School / College Bell* (Classic bell chime)
   - 🛸 *Cyber Warning Siren*
   - ✨ *Energetic Chime*
   - ⚡ *Urgent Repeating Beeps*
   - **🔊 Test Button**: Koyi bhi ringtone select karke test karein aur volume adjust karein.

4. **🎯 Interval Selector**:
   - Default: Har 2 Ghante (120 Mins).
   - Aap testing ke liye 15 Mins, 30 Mins ya 1 Ghanta bhi select kar sakte hain.

5. **🔍 Search & Filter**:
   - Filter by: `All`, `Pending`, `Completed`, ya `Block 1 to 6`.
   - Search bar: Kisi bhi topic (e.g., *DocType*, *WSL*, *ORM*, *Hooks*) ko search karein.
   - **🎯 Jump to Current Pending Day**: Ek click par aaj ke pending day par scroll kar dega.

6. **📝 Personal Notes**:
   - Har din ke card par `+ Add Note` button hai jisme aap us din ka key learning ya error note kar sakte hain.
